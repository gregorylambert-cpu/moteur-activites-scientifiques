# Moteur d'activités scientifiques — V0

Prototype web statique : aucun logiciel à installer pour les testeurs.

## Tester
Ouvrir `index.html` dans un navigateur.

## Mettre en ligne gratuitement
Le dossier peut être publié sur GitHub Pages. Le fichier `index.html` est autonome et embarque les 654 ressources.

## Principe
- recherche libre ;
- âge ;
- durée maximale ;
- activité physique ;
- domaine ;
- source ;
- lien vers la ressource originale ;
- pas de note qualitative ;
- aucune information absente n'est inventée.

C'est un prototype de test utilisateur, pas encore le moteur définitif.
